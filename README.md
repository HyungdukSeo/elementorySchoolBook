# 초등학교 교과서 뷰어 (Elementary School Book)

아이패드에서 공개된 초등학교 교과서 PDF를 받아 읽고, 애플펜슬로 필기할 수 있는 앱입니다.

## 주요 기능

- **학년별 교과서 목록** — 공개 교과서 사이트에서 학년·과목별 목록 자동 표시
- **원클릭 업데이트** — 버튼 하나로 최신 교과서 파일 다운로드
- **PDF 뷰어** — 내장 PDF 뷰어로 교과서 열람
- **애플펜슬 필기** — PDF 위에 직접 손글씨 필기 가능
- **필기 자동 저장** — 필기 내용이 PDF에 함께 저장되어 다음에 열어도 유지
